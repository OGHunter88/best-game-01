Emberfall Keep — an original tower-defence game. The horde walks the ember road toward your crystal: build Spark Spires, Frost Obelisks and Ember Cannons beside the road, upgrade them, and survive all 12 waves, including the Ash Golem. A complete game: title screen, build phases, escalating waves, gold economy, upgrades, selling, win and defeat screens with restart, HUD, pause, 2× speed, and synthesised sound (WebAudio, no files).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests. Screenshot scenes: `?shot=start`, `?shot=build`, `?shot=play`, `?shot=end` (with `&seed=N` for a deterministic frame).
